PropertyFunctions.jl provides functionality for easy access to and efficient
broadcasting over properties, e.g. via `xs .|> @pf $a + $c^2`. The macro
`@fp` uses the inverse escaping convention, e.g. `xs .|> @fp a + c^2`, and
nested properties can be referenced via `$a.b.c` (resp. `a.b.c`).

Broadcasting of functions generated by `@pf` and `@fp` reads only the
referenced columns and is GPU-friendly.

The package also provides `sortby` and `filterby` for sorting and filtering
table-like arrays, and `innermerge` to merge their columns.
